# RED summary

## Repeated baseline failures

1. **Declared originality without testing the visual cluster.** The carousel
   said it used “princípios gerais” while combining several recognizable source
   signatures in one piece.
2. **Treated approximate brand values as sufficient.** All three responses
   lacked exact Datta tokens, type roles, logo assets, placement, and brass
   limits; two placed the logo at the top.
3. **Filled strategic gaps silently.** The paid-ad response invented a broad
   lead-generation objective, a contact destination, and a CTA because the
   brief omitted them.
4. **Confused a concept with a production system.** “Premium”, “strong”, and
   “clean” substituted for concrete grid, hierarchy, safe-area, provenance, and
   export decisions.
5. **Called generic geometry proprietary.** The static response treated `≠` as
   a proprietary brand element without evidence that Datta owns that device.

## Verbatim rationalizations to counter

| Baseline wording | Required correction form |
| --- | --- |
| “Usei princípios gerais de impacto editorial, sem reproduzir a identidade” | Explicit similarity gate based on co-occurring signature elements. |
| “Como não há oferta, público ou landing page definidos, criei uma abordagem ampla” | Conditional contract that preserves unknown launch-critical fields as blockers or placeholders. |
| “Transformei o símbolo ≠ no elemento central e proprietário” | Rule that distinguishes a one-off concept from an approved brand asset. |
| “Arte publicitária premium” | Positive art-direction schema with observable attributes instead of taste adjectives. |

## Guidance forms selected

- Use a **positive output contract** for briefs, static posts, carousels, ads,
  image plans, and QA because the baseline output shape was incomplete.
- Use **required structural fields** for evidence, provenance, objective,
  destination, and assumptions because agents omitted them.
- Use **observable conditionals** for missing launch-critical inputs and for
  organic versus paid asset rights.
- Use a narrow **prohibition plus red flags** only for social-profile refresh,
  fabricated evidence, logo reconstruction, and derivative signature clusters.
